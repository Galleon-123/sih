UNISERVE USER APP — SIMPLE AI BUILD PLAN
==========================================
This plan is written so an AI coding tool can read it and build the app
screen by screen. Every section tells the AI: what to build, what data
to use, and what to connect to the next screen.

---

TECH STACK (keep it simple)
-----------------------------
Framework   : React Native (Expo) — works on Android and iOS from one codebase
Navigation  : React Navigation (Stack + Bottom Tabs)
State       : React Context or Zustand (no Redux needed)
Styling     : NativeWind (Tailwind for React Native) or StyleSheet
Backend     : Mock data (JSON files) for hackathon — no real server needed
Maps        : react-native-maps with a mock moving marker
OTP         : Simulated — generate a random 4-digit number in the app itself
Payment     : Simulated — a "Pay Now" button that shows a success screen
Storage     : AsyncStorage for offline cache

Folder structure:
/app
  /screens       — one file per screen
  /components    — reusable UI pieces
  /data          — mock JSON files
  /context       — global state (user, booking, worker)
  /navigation    — stack and tab setup
  App.js

--------------------------

SCREEN 17 — SEVA SURAKSHA SCREEN
----------------------------------
What to show:
  - Title: "Seva Suraksha Guarantee"
  - Subtitle: "We handle every problem — you are never stuck."
  - Table/card list of 9 scenarios:

  Problem                     | What UniServe does
  No worker available         | Searches partner cooperative / waitlist
  Worker cancels              | Automatic replacement search
  Worker is late              | Revised ETA + replacement option
  Wrong person arrives        | Do not share OTP — report identity mismatch
  Work cost increases         | Your approval required before extra work begins
  Payment fails               | Retry / support ticket raised
  Poor work quality           | 7-day warranty revisit available
  Safety concern              | Cooperative organiser support activated
  Worker no-show              | Priority reassignment + organiser escalated

  - "Go back home" button

This screen should be accessible from:
  - Home screen footer link
  - Booking status screen
  - After a complaint is filed

BUILD ORDER FOR HACKATHON
---------------------------
Build in this exact order so a working demo flow exists at every step:

Step 1: Set up Expo project + navigation skeleton + mock data files
Step 2: Screen 01 + Screen 02 (language + login) → user can log in
Step 3: Screen 03 (home) → user sees services
Step 4: Screen 04 + Screen 05 → user can select service and fill booking
Step 5: Screen 06 → worker match card shows up
Step 6: Screen 07 → map tracking animation
Step 7: Screen 08 + Screen 09 → start OTP and job in progress
Step 8: Screen 11 + Screen 12 + Screen 13 → completion, payment, fair breakdown
Step 9: Screen 14 → rating
Step 10: Screen 15 → no-worker fallback (Seva Suraksha demo)
Step 11: Screen 17 → Seva Suraksha guarantee screen
Step 12: Screen 10 + Screen 16 → extra work approval + complaint (polish)
Step 13: Bottom tabs, notifications, profile screen

At the end of Step 9 you have a complete demo loop:
  Login → Home → Book → Match → Track → OTP → Pay → Rate
